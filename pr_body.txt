💡 **What:**
Optimized `ParticulasCuanticas.tsx` by separating static and dynamic attribute calculations and replacing per-particle `Math.sin` and `Math.cos` calls inside the high-frequency render loop (`useFrame`) with trigonometric expansions and lookup tables.

🎯 **Why:**
The component was calling `Math.sin` and `Math.cos` natively for every single particle on every single frame, causing significant CPU overhead and dropping the framerate. Additionally, the previous `useMemo` setup recreated all positions and sizes whenever the frequency changed, leading to unnecessary allocations and a visual stutter.

📊 **Impact:**
Substantially reduces CPU time spent per frame by eliminating native trigonometric function calls in the hot loop, shifting them to fast array lookups and arithmetic operations. The visual transition when changing frequencies is also smoother since random positions aren't recalculated.

🔬 **Measurement:**
Run `pnpm build` and verify successful types compilation. Run `npx tsx --test` to ensure no functionality is broken. Use the `Next.js` profiler to observe reduced frame rendering time when viewing the 3D particles.
